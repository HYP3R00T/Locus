# Locus

A workspace for study and research, bringing source material, handwritten drawings, and typed notes together.

**Status: PDF library and reader.** The desktop app organizes referenced PDFs into workspaces and folders,
opens them with PDF.js, and saves reading positions in SQLite. Drawing and linked notes remain planned.
